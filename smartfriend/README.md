# Smart Friend

Smart Friend is a Laravel 11 sample application that provides a simple AI chat interface.

## Requirements

- PHP 8.2 or higher
- Composer

## Installation

```bash
composer install
cp .env.example .env
php artisan key:generate
```

## Running the application

```bash
php artisan serve
```

Then open http://127.0.0.1:8000/smartfriend in your browser.
